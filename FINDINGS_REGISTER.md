| **F-010** | Reactive-JPY LSTM Reference Benchmark: Using dataset v1.6.1 and reference training horizons (100 epochs for the Consensus Lifecycle Behavioral Surface; 1500 epochs for the Trend/Volatility Behavioral Surface), LSTM-derived prediction artifacts consistently improved out-of-sample adaptive trading performance within MPML relative to the no-DL baseline.
